# PicotronNest 0.1.0-beta.1

**Prepared first beta candidate — not published.**

Bring your own official Picotron to an Android handheld or phone. This candidate
opens the original workstation and adds fullscreen display, Android input,
translucent game controls and a persistent home for your projects.

## Included

- Runtime import through Android's file picker; no Picotron files bundled.
- Original desktop, editors and native cartridge handling.
- Keyboard/IME, mouse, configurable gamepad and controller pointer input.
- Compact/full touch controls with saved size, opacity and visibility.
- Audio output, session lifecycle and interrupted-launch recovery.
- Cartridge import/export and home backup with non-destructive restore.
- App icon/version, local diagnostic export and bundled open-source notices.

## Requirements and limits

Use a native ARM64 Android device and your own **Picotron 0.3.0d2 Raspberry Pi
64-bit ZIP**. Retroid Pocket Classic / Android 14 has scoped evidence. Other
devices, audible sound, long sessions and physical controller/phone ergonomics
need tester confirmation. Online Picotron features are unavailable in this
candidate. See [the tester checklist](../TESTING.md).

The product package is `art.picotronnest`. It does not replace early lab builds;
transfer saved projects using their backup/export tools. Back up before uninstalling.
