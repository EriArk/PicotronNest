# PicotronNest 0.1.0-beta.2

**Beta prerelease for testing.**

Explore the real Splore catalog, download games and open them directly in your
own Picotron on Android. This update adds the network dependencies used by the
official runtime; Picotron's desktop, editors and Splore remain unchanged.

## New

- Native HTTP(S), Android name resolution and system certificate trust.
- Splore catalog, cartridge downloads and game launch checked on Retroid.
- MIT license for original PicotronNest code; separate dependency notices retained.
- Original device screenshot gallery and an additional screenshot ZIP for articles.
- Failed sessions retain private process receipts; exported reports remain allowlisted.
- Android IME newline/editor actions send balanced Enter events; short input edges
  remain visible across native frames instead of disappearing within one poll.

## Requirements and limits

Use a native ARM64 Android device and your own **Picotron 0.3.0d2 Raspberry Pi
64-bit ZIP**. Picotron is not included. Retroid Pocket Classic / Android 14 has
scoped evidence. Other devices, audible sound, physical controllers and longer
sessions need tester confirmation. Account operations, uploads, VPN/Private DNS,
network transitions and raw socket workflows remain unverified. Use windowed
Splore: its native fullscreen toggle showed incorrect layout.
See [the tester checklist](../TESTING.md).

Install over beta 1 with the same package/signature to preserve imported runtime
and projects. The separate development lab keeps its own storage. Back up before
uninstalling or clearing app data.
