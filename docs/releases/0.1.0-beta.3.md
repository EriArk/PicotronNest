# PicotronNest 0.1.0-beta.3

**Beta prerelease for testing.**

This update adds guided setup, version-flexible runtime import, a cover-grid game
launcher and adjustable sound buffering. Retroid has scoped upgrade, library-launch
and gameplay evidence. Audio listening and broader hardware acceptance remain open.

## Changes

- Three-step first-run wizard explains PicotronNest, guides official ARM64 ZIP
  selection and introduces controls, saving and backups before an explicit launch.
- Import is no longer tied to Picotron 0.3.0d2 or a fixed archive hash. Compatible
  older/newer Linux ARM64 packages may be imported; architecture, package and
  bundled-library checks still apply. Untested versions may fail at runtime.
- Existing installations retain their home and normal direct launch. Runtime
  replacement retains the previous build, with a reminder to back up projects.
- Each runtime gets its own managed execution environment, preventing an older
  cached executable from being reused after switching versions.
- Cancelled/bad-file imports no longer consume the incomplete-import retention
  quota during ordinary retries.
- Sound buffer preferences: Auto, Low latency and More stable, with live changes
  and diagnostic counters. SDL dummy playback uses a sample-count clock.
- A **Your games** button beside the hamburger opens cartridge covers and launches
  local or downloaded games through Picotron's own process API.

## Updating and limits

Install over the existing product APK with the same signature. Do not uninstall
or clear app data unless you have exported your projects first. Back up before
changing Picotron versions: rollback changes the executable/data pair, not
project files modified by Picotron itself.

Picotron is not included. Bring your own legally obtained Linux / Raspberry Pi
64-bit ARM64 ZIP. Windows, macOS, 32-bit and PICO-8 packages are unsuitable.
The bundled SDL2/Linux environment still constrains compatibility; accepting an
archive does not establish that every Picotron release works on every device.

The final APK was installed over the existing product on Retroid Pocket Classic /
Android 14. Grid Rider, Phoenix, Sokofox and Stix Disruption reached interactive
gameplay in the separate lab; a cached Splore cartridge launched from the product
library. The 45 host checks, 13 tools checks and Android 15 audio fixture pass.

**Crackling is not confirmed resolved.** A 123-second Phoenix rerun after the
buffer-reprime fix counted one underrun and adapted to 100 ms. Nobody listened
during that test. Please report your device, audio route and selected buffer mode
if you hear distortion. Longer sessions, other phones, Bluetooth and other
Picotron versions still need testing. Fresh import/replacement/rollback has owned
Android fixture evidence, but the new wizard's full hardware journey remains open.
