# PicotronNest 0.1.0-beta.4

**Beta prerelease for testing — ARM64, Android 8+ manifest floor, target API 36.**
The minimum Android version is not a compatibility guarantee. Picotron is not
included: supply your own legally obtained Linux / Raspberry Pi ARM64 build.

## Changes since beta 3

- **Import cartridge (queue)** opens the Android picker from the running session.
  Copies wait outside the live home. Save and close Picotron, then use
  **Projects and backups > Finish queued imports**. Interrupted copies require
  explicit review; existing cartridges are preserved on name collisions.
- **Import/Export cartridge folder** transfers nested `.p64` and `.p64.png`
  collections through Android's folder picker into a new, uniquely named folder.
  Names and hierarchy are preserved; loose assets are skipped. Transfers require
  a closed session and are limited to 4096 entries, 32 levels and 128 MiB.
  Partial results and incomplete-export warnings are reported explicitly.
- **Save screenshot** exports the original frame as PNG through Android's
  document picker, without host overlays or automatic uploads.
- **Restart Picotron** requests a verified shutdown before relaunching within the
  app. Save first: restart does not preserve unsaved work. Failed shutdowns do
  not silently launch a second runtime.
- **Picotron controls** is reachable from the controller menu. First-use guidance,
  D-pad navigation, configured confirm/cancel and sliders improve discoverability.
  The drawer explains which operations require closing Picotron.
- Supported cartridge names retain mixed-case extensions, spaces and Unicode.
  Unsupported PICO-8 formats receive an explanation rather than being treated as
  Picotron cartridges.
- **Help and community** provides the AbyssTail website, website-maintained Discord
  discovery and GitHub reporting alongside diagnostics.
- Unsaved input settings survive Activity recreation. Android provider transfer
  errors reject incomplete imports; cleanup warnings remain visible even after
  earlier errors fill the bounded details list.
- Product and owned native-fixture builds now support Linux x86-64 tooling.

## Updating and current limits

Install over the existing `art.picotronnest` product APK; version code is **1004**
and the signing identity is unchanged. Back up important projects first. Do not
uninstall or clear application data to update or recover a session.

Save your work and quit Picotron before updating. Wait for the app to finish
closing the session. If **Resume safely** appears, use the recovery flow after
confirming the prior session has stopped; recovery cannot restore unsaved edits.
A recent development update on Retroid reached this recovery screen. Its cause
and recovery completion were not verified before this beta because device control
was shared with another test. A clean beta-4 hardware upgrade/session/recovery
cycle remains an acceptance check.

The changes have scoped host and owned Android emulator evidence, including
provider failures, cancellation, real queue-process interruption, settings
recreation and Back navigation. These tests do not prove a live official Picotron
session, physical controller behavior or compatibility with arbitrary providers.
The final beta-4 APK has not completed fresh physical-device acceptance. Earlier
Retroid/Android 14 evidence applies only to its documented builds and scenarios.

Other Android devices, enforcing ARM64 execution policies, audio interruptions,
Bluetooth, long sessions, external/cloud providers and normal/hung native restart
still need testing. Folder transfers copy cartridges only, not loose project
assets. Signature admission is not proof that a cartridge is runnable. The
Discord action uses the website's community section while a direct redirect is
unavailable. No issue is declared fully device-accepted by this prerelease.

See the [tester checklist](../TESTING.md) and the
[user guide](https://github.com/EriArk/PicotronNest/blob/v0.1.0-beta.4/docs/USER_GUIDE.md).
Report the device, Picotron version, action sequence and exported diagnostic JSON.
